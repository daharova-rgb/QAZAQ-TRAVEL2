# QAZAQ TRAVEL жобасына қойылатын талаптар

## Функционалдық талаптар

1. Пайдаланушы сайттың басты бетін аша алады.
2. Пайдаланушы туристік бағытты таңдай алады.
3. Пайдаланушы туристік орындар туралы ақпаратты көре алады.
4. Пайдаланушы сайт беттері арасында ауыса алады.
5. Пайдаланушы Шарын, Көлсай, Бурабай және Маңғыстау туралы ақпаратпен таныса алады.

## Функционалдық емес талаптар

1. Сайттың интерфейсі қарапайым және түсінікті болуы керек.
2. Сайт беттері браузерде дұрыс ашылуы керек.
3. Сайт HTML5 және CSS3 технологияларын қолдануы керек.
4. Беттер арасындағы навигация дұрыс жұмыс істеуі керек.
5. Сайттағы суреттер дұрыс көрсетілуі керек.
