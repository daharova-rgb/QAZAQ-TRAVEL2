# QAZAQ TRAVEL Use Case

## Жүйенің негізгі пайдаланушысы

Негізгі пайдаланушы — турист немесе саяхатқа қызығушылық танытқан адам.

## Негізгі Use Case-тер

1. Сайтты ашу
2. Басты бетті қарау
3. Туристік бағытты таңдау
4. Туристік орын туралы ақпаратты қарау
5. Сайт беттері арасында ауысу

## Пайдаланушы әрекеттері

### 1. Сайтты ашу
Пайдаланушы сайтқа кіреді және басты бетті көреді.

### 2. Бағытты таңдау
Пайдаланушы Қазақстандағы туристік бағыттардың бірін таңдайды.

### 3. Ақпаратты қарау
Пайдаланушы таңдалған туристік орын туралы ақпаратпен танысады.

### 4. Беттер арасында ауысу
Пайдаланушы навигация арқылы басқа беттерге өте алады.

## Нәтиже

Пайдаланушы Қазақстанның туристік орындары туралы қажетті ақпаратты алады.
