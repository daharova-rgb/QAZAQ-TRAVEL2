# QAZAQ TRAVEL

## Жоба туралы

QAZAQ TRAVEL — Қазақстанның көрікті жерлері туралы ақпарат беретін веб-сайт.

Сайтта Қазақстанның танымал туристік орындары көрсетілген:
- Шарын шатқалы
- Көлсай көлдері
- Бурабай
- Маңғыстау

## Жобаның мақсаты

Қазақстандағы туристік орындар туралы ақпаратты ыңғайлы және түсінікті түрде ұсыну.

## Қолданылған технологиялар

- HTML5
- CSS3

## Жоба құрылымы

- `index.html` — басты бет
- `start.html` — саяхатты жоспарлау беті
- `charyn.html` — Шарын туралы ақпарат
- `kolsai.html` — Көлсай туралы ақпарат
- `burabay.html` — Бурабай туралы ақпарат
- `mangystau.html` — Маңғыстау туралы ақпарат
- `css/` — стиль файлдары
- `images/` — суреттер
